# 참가 전략 (문제해결 부문)

## 1. 대회 핵심 파악
1. 목적: 데이터·AI로 사회·과학 문제 해결 → 국내 연구데이터(DataON) 생태계 확대
2. 문제 유형: **공모 발굴 문제** + **정책지정 문제**(수요기관 제시)
3. 평가 흐름: 문제별 제출 결과 → 우수 모델 후보(서류) → 발표평가 → 문제별 최우수 + 전체 특별상
4. 포인트: "높은 성능의 AI 모델"이 핵심이지만, 발표평가가 있으므로 **정책 활용성·해석 가능성**도 중요

## 2. 문제 선택 기준 (09.15 공개 문제 중)
| 기준 | 확인 사항 |
|---|---|
| 데이터 확보 | 제공 데이터 규모·품질, DataON 추가 데이터 결합 가능 여부 |
| 평가지표 명확성 | 정량 지표(RMSE, F1 등)가 있는가 |
| 경쟁 강도 | 수상 기관(국회도서관·대전시·해양경찰청·수자원공사·대전중구청 등) 문제별 참가팀 수 |
| 팀 역량 적합 | 정형/시계열/텍스트/이미지 중 강점 분야 |
| 스토리 | 수요기관이 실제로 쓸 수 있는 결과인가 |

→ 정책지정 문제는 수요기관 상(우수상 5팀)과 직결되므로 우선 검토 권장

## 4. 차별화 전략
1. **이종 데이터 융합**: 제공 데이터 + DataON 공개 데이터/외부 공공데이터 결합
2. **검증 신뢰성**: 누수 없는 CV, 시계열이면 시간 기준 분할
3. **해석 가능성**: 중요 변수·정책 시사점을 수요기관 언어로 설명
4. **재현성**: `src/` 코드화, 시드 고정, 실행 방법 README에 명시
5. **활용 시나리오**: 대시보드/시연 등 "바로 쓸 수 있는" 형태로 제시
