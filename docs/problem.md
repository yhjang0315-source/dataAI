# 문제 3: 수질·수문·기상 융합 댐·하천 유해남조류 7일 예측

## 과제
1. **주과제(회귀):** 지점별 기준일(base_date) → 7일 후 유해남조류 세포수(cells/mL) 예측
2. **부과제(분류):** 예측 세포수 → 경보단계(해제/관심/경계/대발생)
3. base_date는 실측일만 허용
4. 정답: base_date+7일에 가장 가까운 측정일 값, 차이 ±3일 이내만 채점 (없으면 제외)

## 대상 지점
| 지점 | 수계 | 코드 |
|---|---|---|
| 해평 | 낙동강 | 2011G26 |
| 강정·고령 | 낙동강 | 2011G56 |
| 칠서 | 낙동강 | 2020G33 |
| 물금·매리 | 낙동강 | 2022G05 |
| 대청호 회남 | 금강 | 3008G30 |

## 입력 데이터 (공개 데이터 직접 수집)
| 도메인 | 출처 | 주기 |
|---|---|---|
| 수질·조류 | 조류경보제 측정자료 (물환경정보시스템) | 주 1~2회 |
| 수문 | K-water 다목적댐 운영자료 | 시간/일 |
| 기상 | 기상청 ASOS 종관관측 | 시간/일 |
| 수문 보강 | DataON 「댐유역 하천 일평균수위」 | 일 |

## 라벨 파생
- 경보단계(상수원 구간 기준, 유해남조류 세포수): 해제 <1,000 / 관심 ≥1,000 / 경계 ≥10,000 / 대발생 ≥1,000,000
  - ※ 공식 발령은 2회 연속 초과 조건이 있으나 여기선 측정 단위로 산출 (대회 공지 확인 필요)
- 우점종: Microcystis·Anabaena·Aphanizomenon·Oscillatoria 중 세포수 최댓값

## 평가
| 항목 | 내용 |
|---|---|
| 분할 | 학습 ~2023 / 검증 2024 / 평가(비공개) 2025~ |
| 회귀 | log10(세포수+1) RMSE·MAE, 원단위 R²·NSE |
| 분류 | Macro-F1 |
| 종합 | 회귀 70% + 분류 30% (예시) |
| 목표 | R² ≥0.6, NSE ≥0.5, Macro-F1 ≥0.6 |
| 벤치마크 | 국립환경과학원 AI 녹조 정밀 예측정보 |

## 금지사항
1. 예측값 하드코딩·실측 룩업테이블 금지
2. base_date 이후 관측값 입력 금지 (누수)
3. 재현 결과가 제출물과 다르면 실격 → 시드 고정·전체 파이프라인 스크립트화

## 핵심 설계 포인트
1. 주기 다른 시계열 정렬: 수질(주간) ↔ 수문·기상(일) → base_date 기준 과거 창 집계
2. 융합 특징: 누적강우(3/7/14일), 체류시간 대리(저수량/방류량), 수온 이동평균·추세, 직전 세포수 lag·변화율
3. 결측: 유량 증가 시 미채수 → 결측 여부 플래그 + 보간 전략 비교
4. 선행연구: log세포수와 상관 수온 0.63 > 월 0.37 > 유입량 0.19 > 방류량 0.19
